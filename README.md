# 🎮 MathLand – Learn Math Through Stories

 Overview

MathLand is an interactive educational platform designed to make mathematics fun, engaging, and easy for children. Instead of traditional worksheets and repetitive exercises, MathLand transforms learning into an exciting adventure where students explore magical worlds, complete quests, solve mathematical challenges, and earn rewards.

The platform combines storytelling, gamification, and personalized learning to help children build strong mathematical foundations while enjoying the learning process.

---

 Objectives

* Make mathematics enjoyable and less intimidating for children.
* Improve problem-solving and critical thinking skills.
* Encourage consistent learning through rewards and achievements.
* Provide parents and teachers with insights into student progress.
* Create an engaging digital learning environment using modern web technologies.

---

 Features

 Story-Based Learning

Children progress through different fantasy worlds where each level introduces a new mathematical concept.

Examples:

* Cross a bridge by solving addition problems.
* Open treasure chests using multiplication.
* Rescue characters through fraction challenges.
* Unlock new worlds by completing math quests.

 Gamified Experience

* Coins and rewards system
* Achievement badges
* Level progression
* Daily challenges
* Experience points (XP)

 AI Math Helper

* Provides hints for difficult questions
* Explains solutions step-by-step
* Generates additional practice questions
* Supports personalized learning

 Student Dashboard

* View completed levels
* Track achievements
* Monitor learning progress
* Access unlocked worlds

 Parent Dashboard

* Monitor child performance
* View topic-wise progress
* Identify weak areas
* Track learning activity

 Progress Analytics

* Accuracy tracking
* Time spent learning
* Topic performance reports
* Learning recommendations

 Voice Narration

* Story narration for younger learners
* Interactive learning experience
* Improved accessibility

 Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/MathLand.git
```

### Navigate to Project Folder

```bash
cd MathLand
```

### Install Frontend Dependencies

```bash
cd frontend
npm install
```

### Install Backend Dependencies

```bash
cd ../backend
npm install
```

### Start Backend Server

```bash
npm start
```

### Start Frontend Application

```bash
cd ../frontend
npm start
```
